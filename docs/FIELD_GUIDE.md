# 字段与分类设计 · 0.3.1

目标是先让作者把文字安全地放进来，再逐步找回、关联和整理。界面中的“必填”指**完成当前动作所需**，不是要求作者先把整部小说规划完。“选填”必须允许留空，默认值应清楚、可修改。

| 当前动作 | 必填 | 选填或已有默认值 | 留空时的行为 |
| --- | --- | --- | --- |
| 打开加密资料库 | 资料库密码；首次设置需再次输入 | 无 | 不创建未加密资料库 |
| 创建写作空间 | 无须提供故事构思 | 创作方向、一句话想法、已有稿件、作品名 | 使用本地可编辑模板和“未命名作品”；已有稿件可稍后导入 |
| 新建作品或章节 | 无 | 作品名、章节名 | 使用默认名称，可随时重命名 |
| 编辑章节或大纲 | 无 | 名称、正文 | 空白可保存，允许先占一个位置 |
| 粘贴资料 | 粘贴内容 | 资料名、主要分类 | 名称为“未命名资料”，分类为“待整理” |
| 导入资料文件 | 选中 TXT / Markdown 文件 | 资料名与分类无需预填 | 文件按原名保存到“待整理” |
| 整理资料 | 无 | 主要分类、关键词、关联章节 | 资料仍可通过标题和正文搜索 |
| 新建任务 | 一件具体的小事 | 关联章节 | 任务仍可单独保存 |
| 使用自己的模型 | 连接时：HTTPS 地址、API Key、对话模型 ID、向量模型 ID；使用相应动作时：问题或创作要求 | token 上限已有默认值；模型分类可忽略或撤销 | 不连接模型仍可写、整理、搜索和备份 |
| 恢复加密备份 | 备份文件及其解密密码 | 旧版明文备份无需密码 | 不会覆盖当前作品；只在校验成功后生成副本 |
| 手动 WebDAV 快照 | 使用时：文件地址、用户名、网盘应用密码；远端已有文件时还需解密密码 | 不使用网盘可一直跳过 | 本地写作与备份仍可用 |
| 章节协作 | 连接时：文件夹地址、用户名、应用密码、独立协作口令 | 正文可从空白继续写 | 不连接时保持普通本地编辑 |

## 分类按“以后怎么找”设计

一份资料只有**一个主要分类**，避免每次输入都要完成多维表单。跨人物、地点、章节的内容，可以用选填关键词和章节关联补充；拿不准就留在“待整理”。改分类不改原文，规则和模型建议均须作者接受。

| 主要分类 | 放入示例 | 写作时能解决的问题 |
| --- | --- | --- |
| 待整理 | 一句未成熟的想法、散落文件 | 先接住内容，之后再决定用途 |
| 人物 | 目标、动机、弱点、人物关系 | 这个人为什么会行动？ |
| 情节冲突 | 事件、阻碍、转折、抉择 | 下一步发生什么，为什么？ |
| 场景设定 | 地点、氛围、世界规则、规则代价 | 故事发生在哪里，有何限制？ |
| 线索时间 | 伏笔、回收点、时间线、事件先后 | 线索何时出现，前后是否矛盾？ |
| 灵感碎片 | 画面、句子、尚未落章的点子 | 以后可以从哪里继续写？ |
| 外部参考 | 摘录、资料来源、研究笔记 | 这条事实或素材从哪里来？ |

分类不是故事质量评分，也不是要求按固定顺序写作。人物目标与阻碍、情节、场景等是常见的小说组织线索；作者可以按照自己的写法组合。没有可靠线索时，本地规则返回“待整理”，模型分类也被要求允许这一结果。

## 认知负担与验收

本版针对可能遇到启动困难、分心或组织负担的作者，采用单步输入、默认待整理、渐进展开的附加字段、可见保存状态和可找回原文；这些选择也适用于不具有 ADHD 的作者。ADHD 表现存在个体差异，界面设计不能替代临床支持，也尚未经过 ADHD 作者可用性研究。[NIMH](https://www.nimh.nih.gov/health/publications/adhd-what-you-need-to-know) 记录成人可能面临计划、组织和完成大型任务的困难；[Purdue OWL](https://owl.purdue.edu/owl/subject_specific_writing/creative_writing/writers/fiction-basics/writing_compelling_characters.html) 说明人物目标、冲突和场景在小说构建中的关系。这些是设计依据，不是本产品效果证据。

后续真人任务应分别观察：首次保存一段文字所需时间、非必填字段是否阻碍提交、资料放入后能否找回、分类误判能否纠正、作者是否理解“待整理”、是否有人觉得分类过多或提示打断写作。记录原话与实际操作，不用主观诊断标签代替研究。
