## 界面验收

正式本机服务的独立 QA 区：设置合成密码 → 输入创作要求 → 预览并创建作品 → 编辑保存 → 刷新锁定 → 解锁后文字一致 → 主动锁定。

另在 `tests/mock_services.py` 启动的独立合成环境运行实际前端与网关；出站传输被进程内固定结果替换，不访问外网：

- 输入合成模型配置，密钥字段清空。
- 建立两个片段的索引，再点击复用已有片段；查询后计入 token 与调用次数一致。
- 问答显示 [S1]、来源正文、版本和字符位置。
- 分类建议可接受、撤销；结果不直接改写正文。
- 自然语言草稿先预览，再保存独立新章节。
- 索引更新后语义联想资料，接受后建立章节引用。
- WebDAV 读取不存在的文件 → 条件创建密文 → 使用密码重新读取并校验 → 识别已处理快照，不重复恢复。
- 历史整理显示版本数量、可清理数量和容量。
- 该合成 UI 验收标签错误/警告日志为零。

备份的数据恢复由真实 IndexedDB 测试验证。本轮没有重复真实文件选择器上传/下载压力验收；WebDAV 首次跨设备恢复通过底层恢复逻辑与模拟协议分别覆盖，尚未作为真实设备流程验收。
