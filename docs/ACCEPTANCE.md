## 合成端到端环境

```sh
python3 -B tests/mock_services.py --port 8772
```

打开 `http://127.0.0.1:8772/?qa=1`。这是合成服务：所有远端请求在进程内被替换，禁止外网访问。基础地址填写 `https://example.com/v1`，模型名填 `fixture-chat` 与 `fixture-vector`，密钥为任意至少八字符的合成值。网盘填写 `https://example.com/novel.json`、合成用户名/密码。该服务器的远端快照只在内存保存，停止后消失。不能拿它验证模型质量、真实延迟或账单。

依次：创建作品 → 添加资料 → 建立索引 → 语义检索 → RAG 引用 → 分类接受/撤销 → 资料关联 → 草稿另存 → 网盘首次上传 → 读取重复快照 → 加密备份恢复。完成后停止合成服务器。

## 真实模型服务（待验）

1. 在服务商创建专用限额 key；在应用内填写，不发聊天或截图。
2. 核对 endpoint、两个模型 ID 及支持 Chat Completions/Embeddings。
3. 用一份合成材料建立索引；确认 usage 与账户账单有对应记录。
4. 建立第二批，确认未修改片段不重发；修改/删除材料，确认旧版本不被回答引用。
5. 用有证据、无证据、含恶意指令三类问题测试；手工评估回答与出处是否一致。
6. 撤销 key / 耗尽测试限额 / 断网，确认错误可恢复，正文保留，无自动付费重试。
7. 清除本机会话，确认后续调用要求重新连接；检查备份中无凭据字段。
