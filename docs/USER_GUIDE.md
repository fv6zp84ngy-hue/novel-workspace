# 第一次使用

1. 点击“新建故事”，选择新故事或已有稿件。
2. 选择一个创作方向，或直接写一句需求；有稿件可粘贴原文。
3. 预览并修改作品名，创建后写第一段。注意顶部保存状态。
4. 在“资料”放入 TXT/MD 或文字；用“找资料”搜索人名或片段。
5. 打开原文，在侧栏把资料关联到某章；回到正文即可查看。
6. 在“任务”记下一件小事，可关联章节，完成后勾选。
7. 定期打开“备份与恢复”，导出完整备份并确认下载落盘。

想法、作品名、章节名都可先留空；创建时只需设置资料库密码。放入资料时，粘贴方式只要内容，文件方式只要选中文件。分类、关键词和关联章节可稍后补，默认“待整理”不会妨碍搜索。资料箱中的“分类例子”可帮你按人物、情节、场景、线索时间、灵感和外部参考选择主要位置；选错可以再改。详细条件见 [必填与选填指南](FIELD_GUIDE.md)。

误改：用历史版本恢复；误删：到回收站找回；版本冲突：保留修改副本或先导出文字。保存失败时不要清理网站数据。

换电脑、浏览器、端口或网址：先导出完整备份，再到新地址恢复。恢复会创建新副本；它不是实时同步。来源不明的备份不要导入。当前模板不是 AI 问答。

## 0.2.0 密码、模型与网盘

首次启动先设置资料库密码；每次重新打开均需解锁。完整备份使用导出时的资料库密码，TXT 是明文。恢复加密备份时先填写备份密码，再选择文件；若密码错误，重新填入后再次选择文件。忘记密码无法找回。

“安全与服务”中填写自己的 HTTPS API 基础地址、API Key、对话模型和向量模型。只连接账户不会调用付费模型。再到“智能助手”按顺序建立一批索引、输入问题、查看出处、点击生成回答。每次建立最多十六个片段，大作品需要继续点击；索引费用由你的账户承担。

同一面板还可按内容分类、联想章节资料，或从一句话生成草稿。结果先预览，保存为新章节；原稿保留。更换模型后索引独立，可在设置中清理旧缓存。

WebDAV 需填写完整文件 URL、用户名、应用密码和远端快照解密密码。先读取：没有文件可首次上传；已有陌生快照则先恢复为本地副本。上传用本机资料库密码加密。发生远端版本冲突时重新读取并保留双方内容。同步由你手动触发，不会自动合并两个设备的同章修改。

历史整理先预览，再下载完整加密备份并确认文件落在电脑上，最后删除可清理版本。重要恢复节点保留。离开前“保存并锁定”；要立即清除所有服务会话，可停止 Python 进程。

## 打开同一章的协作编辑

第一台设备先导出完整加密备份，第二台设备恢复为作品副本；这一步让两端持有同一章节的协作编号。两端分别打开同一个章节，点击“协作编辑”，填写同一个已存在的 WebDAV 文件夹 HTTPS 地址（以 `/` 结尾）、网盘用户名/应用密码和相同的协作解密口令。连接后在弹窗中的协作正文输入。状态提示本机保存与多端同步；前台约每三秒检查远端。

远端改变后正文会自动合并。若远端口令错误、网盘断开或文件变了，本机内容仍保留，可点“立即检查同步”或稍后重新打开。不同设备初次加入时，本地稿与远端不同会先生成独立副本。结束时关闭协作窗口；普通正文编辑器显示最终保存结果。章节标题、任务、资料、删除和目录不通过此入口自动合并。
