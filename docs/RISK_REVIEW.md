# 风险复查 · 0.3.1

范围为公开源码、本地存储迁移、模型与 WebDAV 网关、备份、容量整理及合成故障测试。不是安全认证或线上渗透测试。

| 风险 | 已实现控制 | 剩余边界 |
| --- | --- | --- |
| 稿件/备份明文 | 本机 AES-GCM 密文、完整备份默认加密 | TXT 明文、解锁内存、旧磁盘残留 |
| 历史持续增长 | 保留策略预览、备份后人工清理、缓存清理、40 MiB 限制 | 无自动扩容、大型库性能未验 |
| 付费失控 | 显式点击、批次/输出/频率/会话 token 上限、usage、无自动重试 | 服务商金额限额需自行设置；未知失败可能计费 |
| 密钥泄漏 | API Key 仅本机内存、不入库备份或日志，闲置清理 | 同机恶意进程与解锁网页不受此保护 |
| SSRF / 跨站调用 | 公开 HTTPS、DNS IP 固定、TLS、拒绝重定向、Host/Origin/capability | 未作专业主动渗透验证；本地高权限软件可绕过浏览器边界 |
| 云端覆盖 | 首次条件创建、后续强 ETag、412 停止、恢复副本 | 服务商条件写入实现必须实测；非自动合并 |
| 模型错误/注入 | 引文隔离、无工具权限、分类枚举、版本和引用编号校验、作者预览 | 不保证语义忠实；不能自动相信回答 |
| 浏览器驱逐/磁盘满/突然关闭 | 原子事务、失败保留草稿、加密导出、模拟故障 | 最后未保存字符、真实硬件故障仍待验 |
| 发布敏感信息 | 固定白名单、模式检查、无 Git/真实稿件/凭据 | 模式扫描不代替人工复查；远程 CI 尚未运行 |

CSP 允许脚本访问同源本机 API，不允许直接跨源请求。页面无第三方脚本。网关只运行在用户设备，不处理其他用户账户。使用独立可信 origin；GitHub Pages 可提供基础静态界面，无法运行 Python 网关。

发布时不携带浏览器数据、下载备份、提交身份或旧项目材料；源码 ZIP 使用发布清单构建。用户的真实账户联调与设备验收记录应脱敏，不要上传真实响应、密钥或稿件。

## 章节协作新增风险

| 风险 | 控制与边界 |
| --- | --- |
| WebDAV 不是推送服务 | 前台约 3 秒轮询、后台约 10 秒；网络和服务商可能延迟更久，不承诺亚秒级 |
| 同时修改同一句话 | Yjs CRDT 更新收敛；保留版本历史和副本，语义仍需作者核对 |
| 离线后丢更新 | 正文与 CRDT 状态同一加密事务本机保存；未完成自动保存的最后输入仍可能丢失 |
| 重复/过期/冲突上传 | 条件 GET/PUT，412 取回合并并有限重试；持续失败只保留本机且显示状态 |
| 文件被篡改或错连作品 | AEAD 验证、章节 `syncId` 校验；无共同基线先保留独立本地副本 |
| 扩容/历史 | 每章字符和 CRDT 更新大小限制；未实施跨设备安全压缩，长时间高频协作需另测 |
| 供应链 | 固定 Yjs/lib0 版本，预构建浏览器文件，随包许可证；远程 CI 尚未验证依赖重建 |

合成双窗口测试不是两台真实设备或真实网盘验收。
