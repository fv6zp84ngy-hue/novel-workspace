# 需求核对 · 0.3.1

结论：本地写作和保护链路可用，智能能力及 WebDAV 接口已落地；不能宣布所有需求均已完成生产验收。

| 需求 | 交付状态 | 边界 |
| --- | --- | --- |
| 聚焦新手小说作者 | 已实现 | 保留此前作品、章节、资料、任务等功能 |
| 场景入口与开放表达 | 已实现 | 两条开始路径、两行八类场景、本地模板；可选 AI 草稿入口 |
| 字段必填/选填与低负担整理 | 已实现，真人体验待验 | 首次想法、名称、分类可跳过；资料默认待整理；按小说技法找人物、情节、场景与线索；自填内容不会被场景示例覆盖 |
| 智能归类 | 已实现，真实服务待验 | 本地规则 + 模型分类、理由、预览、拒绝、接受和撤销 |
| 索引 / 语义检索 | 已实现，真实服务待验 | 持久化加密向量、分片增量、模型隔离、过期过滤；基础关键词为扫描 |
| 联想与引用 | 已实现，真实服务待验 | 关键词与向量相似度建议，接受后建立引用；不是知识图谱推理 |
| RAG 问答 | 已实现，真实服务待验 | 显式发送、出处、原文位置和版本校验；仍需作者核对事实 |
| 真实 AI 创作 | 接口已实现，真实服务待验 | 用户一句话请求→预览草稿→保存新章节，非模板冒充 AI |
| 用户承担模型 token | 已实现 | 用户 API Key、本机会话预算和 usage；无转售或平台代付；模型账单以服务商为准 |
| WebDAV 云同步 | 已实现合成环境，真实网盘待验 | 整库手动密文快照；章节正文打开协作窗口时约 3 秒轮询、加密传输、CRDT 自动合并；标题、任务和资料仍不同步 |
| 本机稿件与完整备份加密 | 已实现并做浏览器验证 | 密码不可找回；TXT 是显式明文导出；旧磁盘残留不能保证清除 |
| 长期历史容量 | 已实现基础治理 | 预览、备份后手动清理、保留关键版本、向量缓存清理、40 MiB 上限；无无限容量承诺 |
| 保存和异常恢复 | 已实现并做合成验证 | 版本冲突、事务失败、错误密码、密文篡改、模拟配额不足 |
| 实体设备与极端故障 | 未完成真实验证 | 已补可执行清单；仍需手机、真实 IME、磁盘耗尽、断电等证据 |
| 零技术、零学习 | 产品目标，尚未证明 | 基础操作无需模型；源码启动与 BYOK/WebDAV 设置仍有技术门槛，需真人测试 |
| 开源文档与发布包 | 已准备 | PRD、Spec、设计、开发、测试、风险、MIT 与 CI；远程发布/CI 未验证 |

没有测试过的场景保持“待验”。不将合成模型输出、模拟网盘或注入故障写成真实业务/设备表现。[测试记录](TEST_REPORT.md) · [后续验收](ACCEPTANCE.md)
