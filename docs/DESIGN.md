# 交互设计

使用浅底、深色正文与暖色强调，沿用 CSS variables。界面用“写作”“资料”“找资料”“备份与恢复”等作者能理解的词。

开始页：新故事 / 已有稿件 → 两行可横向浏览的八类创作需求 → 一句话描述 → 预览结构与作品名 → 一次保存并进入作品。已有稿件可先粘贴原文，或稍后导入。模板不会覆盖原稿。

工作台：左侧作品与章节；中间正文；侧栏显示相关资料。移动宽度折叠章节目录。资料默认“待整理”，无需先建立分类体系；搜索结果可回到原文，引用用明确按钮创建或取消。

保存状态必须区分正在保存、成功和失败。版本冲突显示保留副本和导出当前文字，避免静默覆盖。恢复前先校验并预览，完成后形成新副本。

英文覆盖开始页和模板；主导航、恢复和错误信息仍以中文为主。真实手机、屏幕阅读器和新手无指导任务测试尚待补齐。

## 0.2.0 安全与智能扩展

首次进入增加密码设置；已有加密库只显示解锁入口。忘记密码不可恢复，迁移不可由旧版打开，须在设置前说清楚。解锁后仍保留原开始链路，模型配置不是写作前置条件。

顶栏增加“智能助手”和“安全与服务”。智能助手按“建立索引 → 找到出处 → 生成回答”推进；配置、网盘、历史容量集中在可折叠设置内，避免基础写作导航膨胀。分类接受/忽略/撤销、草稿另存、关联资料均需作者主动操作。

费用可见：每次调用后展示 token 计入量；按钮说明发送对象与范围。服务不可用时保留本地功能。同步使用用户熟悉的“读取”“恢复副本”“上传”表达，不将快照包装成实时同步。

## 0.3.0 章节协作编辑

协作入口放在章节编辑器内，只有选中章节才出现。连接页只要求一个 WebDAV 文件夹、网盘应用密码和独立协作口令；帮助文字先说明需要把同一作品的加密备份导入另一设备。连接成功后直接显示正文编辑框、同步状态、立即检查和保存副本，避免暴露 CRDT、ETag 等实现术语。

每章有稳定协作编号，对应远端一个加密文件。进入时先读取远端；首次本地正文与远端不同时自动保存接入前副本。前台约每 3 秒、后台约每 10 秒检查变更。正文变更先落本地加密库，再发送加密的合并状态；远端写入使用版本条件，冲突时重新读取并合并。关闭协作窗停止轮询并清除本次输入的凭据。普通写作、资料、索引、问答和快照备份仍按各自原有入口使用。

状态语义区分“准备保存”“本机已保存，等待网盘同步”“多端已同步”“仅本机保存”。网盘故障时作者可继续写，本机内容保留；同一句的并发修改仍需作者检查语义。此功能不承诺亚秒级协作、多人光标、章节标题与资料字段合并。完整协议与失效处理见 [实时合并设计](LIVE_MERGE_DESIGN.md)。

## 0.3.1 字段与资料分类

表单按“完成当前一步”标注必填，而非把完整创作规划当门槛。首次创建可跳过想法、方向、标题和已有稿件；粘贴资料只需正文，文件导入只需选择文件。高级服务折叠在设置中，连接时才显示相应必填条件。正文、标题和资料分类均可之后修改，保存状态始终可见。

资料采用“一个主要位置 + 可选关键词 + 可选章节关联”。默认“待整理”能接住尚未成形的点子；人物、情节冲突、场景设定、线索时间、灵感碎片、外部参考覆盖常见写作检索任务。分类提示先解释“以后在哪儿找”，再给小说技法例子；建议不会自动应用。导入弹窗将分类放在展开项中，避免作者保存一句话前先作结构决策。细则与待做的真实用户任务见 [字段与分类设计](FIELD_GUIDE.md)。

## 0.4.0 首次使用路径

Treatment 首屏先让作者选择“我有一个故事想法”或“我已经写了一些，但有点乱”。新故事将开放表达放在第一位，场景模板收进次级入口，空白开始始终可用；粘贴稿件的路径直接提供内容输入和 TXT / Markdown 文件选择，不要求先分类。Control 保留旧入口，两个版本共用编辑器和资料能力。

没有模型配置时，点击继续会使用本地模板创建作品、故事大纲、第一章和创作起点资料卡。原始输入保留且可编辑；创建过程不自动发送给模型。迁移成功后将作者带到本地搜索，尝试找回刚导入的一段内容。

本地漏斗页是测试工具，不进入普通写作主导航。它展示会话级 F0–F5、TTFA / TTFV，支持导出；清空事件需勾选确认。事件只在独立 IndexedDB 存储并由作者主动导出。实验变体可通过 URL 固定，避免账号和服务端分流。真人测试之前，页面结果仅用于工程验收和小样本观察。
