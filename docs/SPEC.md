## 数据与加密

逻辑 schema 保留 works、documents、revisions、sources、relations、tasks、meta；IndexedDB 升级为 v2。迁移在一个事务内清空旧明文存储并写入 meta 中唯一 encrypted-vault 记录。记录仅包含固定编号、epoch 和密文 envelope。解锁后的数据在页面内存，写入时整体加密并比较 epoch；另有文档 expectedRevision 检查。过期写入拒绝，不重试覆盖。

AES-256-GCM；随机 12 字节 IV；随机 16 字节盐；PBKDF2-SHA256 600,000 次；密码 12–1024 字符；密钥不可导出。完整备份复用本库派生密钥与盐，但每次使用新 IV。格式绑定 AAD。支持旧版明文备份导入，再落入加密库。并非安全擦除，不能消除旧浏览器/磁盘残留。

解密后快照最大 40 MiB，加密 JSON 导入最大 56 MiB。每次保存整体快照，CPU/内存与库大小相关；不适用于无限增长资料库。历史整理保留每文档最近 5–200 个版本、首个版本及 create/setup/restore 节点。用户预览、下载备份并确认后，事务内重新计算，只删除预览仍可删的编号。当前正文、原始文件和回收站不会被删。

## 检索与生成

基础关键词为本地文本扫描。可选向量索引存于加密 meta 中，键由作品与 endpoint/model 的 SHA-256 指纹组成；不保存密钥。片段长 1,000 字符，重叠 100 字符；片段编号含文档 UUID、revision、起点。每次显式发送最多 16 个片段；新增/修改的片段重新嵌入，未修改的复用。删除与过期片段不参与召回。更换服务/模型形成独立索引，支持清理缓存。

Embedding 返回值需索引完整、有限数值、非零、同维度；最多 8,192 维。余弦排序取前 5 个候选，不设跨模型通用置信阈值；界面要求作者核对相关性。RAG 再次显式发送问题及候选，引文通过 JSON 分隔并作为不可信文本；生成前后校验资料版本，回答需包含有效 [S1] 等编号。编号校验不能保证语义忠实，不构成消除幻觉的承诺。

模型分类仅可选预定义类别，先预览理由，保存使用版本检查；撤销也检查版本。联想接受后创建现有章节引用，可移除。创作请求最多 4,000 字，草稿独立保存，不覆盖正文。兼容 `/chat/completions` 和 `/embeddings`；使用 max_tokens 和 temperature，部分特殊模型可能不兼容，需真实服务验收。

## 本机服务与费用

仅绑定 127.0.0.1；POST 必须匹配 Host、Origin、JSON 类型；每会话随机 capability，闲置一小时失效，最多下一分钟清理。API Key 仅 Python 内存；网页中输入后清空。WebDAV 凭据仅单次请求使用。支持主动清除或停止服务；关闭页面并不立即销毁服务端凭据。

出站仅公开 HTTPS / 443；禁止 URL 账号、查询串、片段、私网/保留地址。解析全部地址并检查，再固定目标 IP、按原 hostname 验证 TLS；不跟随重定向。模型上下文/输出有上限，每会话每分钟最多 10 次模型请求，无自动重试；按 UTF-8 字节与输出上限预留 token，有有效 usage 后改为实测，未知失败保留预留。它不是账单硬限额，服务商预算才是最终约束。当前仅 token 计数，不估算不同模型的金额。

## WebDAV

用户提供已存在目录内的完整文件 HTTPS URL、用户名和应用密码。GET 校验密文/备份后，以新 UUID 恢复副本；首次 PUT 带 If-None-Match: *，后续带已查看且保留快照的强 If-Match。412 停止写入。没有强 ETag 则不支持覆盖；服务商是否遵守条件写入仍需实测。

最近 10 份已处理快照的密文摘要按 endpoint 哈希记录于加密 meta，避免同一快照反复恢复。不同快照仍按副本导入，没有自动正文合并或完整跨设备去重。恢复备份不导入 meta 缓存。只上传加密 envelope，不上传凭据；远端可见文件地址、大小、时间等元数据。

## 章节正文协作 · 0.3.0

普通写作保持原有流程。“协作编辑”仅在章节出现，打开后才启动。Yjs 的 `Y.Text` 合并正文；每次输入先更新页面内 CRDT，约 700 ms 后通过 `saveLiveState` 同一加密事务提交可见正文、版本快照和 CRDT 更新。浏览器关闭或网络故障后，以本地密文恢复未上传更新。

每章以稳定 `syncId` 命名协作文件：`<用户文件夹>/<syncId>.live.json`。从整库备份恢复副本会重映射本地文档 ID，但保留原章节 `syncId`，所以第二台设备可加入同一章。新加入时若本地正文与远端不同、且没有本地 CRDT 基线，先建立“接入前本地副本”，再接入远端，不猜测共同祖先。

WebDAV `GET` 使用强 ETag 条件读取，304 不重传正文；`PUT` 首次条件创建、后续 `If-Match`。412 会重新读取、解密、应用并合并远端 CRDT 更新，最多重试三次。持续竞争、弱 ETag、网络故障、口令错误和密文篡改时暂停远端覆盖，保留已写入本地的正文。协作文件是 AES-GCM 密文，网盘口令和协作口令只留当前窗口内存。每章最多 25 万字符、单份 CRDT 更新最多 2 MiB；达到上限时提示拆分章节，不裁剪已写文字。

轮询前台约 3 秒、后台约 10 秒；浏览器会限速后台计时器。没有 WebSocket 推送、在线光标、人员状态或亚秒级承诺。两端的操作会收敛，但同时改写同一句话的语义需作者核对。普通编辑器及同一章节的多标签并发仍以版本检查保护；协作窗口不自动合并标题、任务、目录、资料和删除。

依赖固定在 `package-lock.json`，`vendor/yjs.mjs` 是预构建浏览器文件，许可证见 [第三方许可](../THIRD_PARTY_LICENSES.md)。开发者修改版本后运行 `npm ci` 与 `npm run build:crdt`，再跑浏览器测试。

## 首次使用漏斗 · 0.4.0

`src/analytics.mjs` 使用独立 IndexedDB（数据库版本 2）保存最多 10,000 个最近事件；达到上限时按 `ts_ms` 删除最旧记录。事件 ID 与每标签页 session ID 为随机 UUID；sessionStorage 保持同标签页刷新状态。`?onboarding=control|treatment` 显式固定变体，未传参数时默认 treatment。

事件属性只允许固定事件名、`new_story|migrate_existing` 路径、`natural_language|template|blank|paste|file` 入口方式、白名单状态枚举、内容长度桶和结果数量桶。不允许传任意自由文本；输入的 `content`、`text`、`prompt`、`title`、凭据和搜索词不会通过属性清洗。数据库不加密，因为它不含创作内容或账号标识，但仍会在本机保留随机会话行为记录。作者可在调试页手动导出或清空。

`src/funnel.mjs` 从当前标签页事件重放状态，仅为同一 session 推导首次价值与深度交互。控制/实验数据不上传，`scripts/analyze_funnel.py` 只在本地读取主动导出的 JSON，按 session 与变体计算完成率和中位 TTFA / TTFV。首次使用创建链路遵循既有显式授权：不会因为模型已配置就自动发送作者原文。
