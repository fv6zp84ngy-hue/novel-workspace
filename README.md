# 未完待续 · Novel Workspace

给刚开始写小说的作者一个安心放文字的地方。先写下想法，之后再整理人物、章节和资料；不需要一开始就把整部小说规划好。

## 这是什么

Novel Workspace 是一个在自己的电脑上使用的小说写作空间。章节正文、大纲、人物和灵感资料可以放在一起，之后通过搜索和关联找回来。资料分类可以稍后再做；拿不准时先选“待整理”。

资料保存在浏览器的加密资料库里。基础写作不需要 AI 账户；需要模型时，可以自行连接自己的模型服务并承担服务商费用。详细功能和安全边界请看[技术与项目说明](README.TECHNICAL.md)。
