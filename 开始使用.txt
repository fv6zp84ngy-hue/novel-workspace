一、第一次使用
1. 电脑需要 Python 3.10 或更新版本；不需要 Node、npm、模型账户或下载编译依赖。
2. 把 novel-workspace-latest.zip 完整解压到一个自己的文件夹。不要在压缩包里运行。
3. macOS：双击 Start.command。Windows：双击 Start.bat。
   Linux：在此文件夹打开终端，运行 sh Start.sh。
4. 新用户在“启动端口”处直接回车。浏览器会打开 http://127.0.0.1:8765/。
5. 自己设置资料库密码，开始写作。保留启动窗口；结束前等文字显示已保存，再按 Ctrl+C。

二、已经有本机稿件时的注意事项（可选）
1. 在旧版“备份与恢复”导出完整加密备份，放到项目目录外；记住资料库密码。
2. 记住原网址与浏览器，例如 http://127.0.0.1:8777/，需要沿用 8777。
3. 关闭旧版网页，在原启动窗口按 Ctrl+C 停止旧服务。
4. 将 ZIP 里的全部文件和目录内容（含 .github、.nojekyll 等隐藏项）复制到旧项目根目录（能看到 index.html 的那层），合并目录，替换同名文件。
   不要把整个旧文件夹删除；不要另套一层 novel-workspace-版本号 文件夹。
5. 双击新启动文件，输入原端口数字。继续在原来的浏览器、原网址打开并解锁。
6. 核对旧作品、标题和正文仍在，再继续写作。保留升级前备份。

作品保存在浏览器的加密资料库，不在程序文件夹里；本次升级不修改稿件数据库结构。
不同浏览器、不同用户配置、localhost 与 127.0.0.1、不同端口都是不同存储位置。
如果看到空库，先核对原浏览器和完整网址，不要清理网站数据或删除旧库。
模型密钥与网盘连接在服务进程内存中，重启后需要重新连接。

三、常见问题
- 不要双击 index.html：浏览器直接打开文件无法正常加载模块和资料库。
- “需要 Python”：先安装/升级 Python 3.10+，再重新打开启动文件。这不是免运行环境的独立桌面应用。
- 端口被占用：先停止旧启动窗口里的服务，再重新打开。不会自动换端口。
- 浏览器没打开：手动复制启动窗口显示的网址到原浏览器。
- macOS 不允许启动：可在系统允许的情况下右键 Start.command → 打开；或在终端进入此目录运行 sh Start.command。
- ZIP 解压工具丢失执行权限：在终端进入此目录运行 sh Start.command（无需修改系统安全设置）。
- Windows 找不到 Python：确认 Python 安装可由 py 或 python 命令启动。
- 进阶指定端口：python3 -B scripts/launch.py --port 8777（Windows 可用 py -3 替代 python3）。
