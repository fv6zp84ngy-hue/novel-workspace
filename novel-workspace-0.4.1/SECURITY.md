# 安全说明

适用范围是个人本地小说工作台，Python 网关不得改为公网多用户服务。

已实现：AES-GCM 加密快照、PBKDF2 密钥派生、密码解锁；原子迁移与提交；版本冲突拒绝；备份结构和哈希校验；HTML 转义；同源 POST / 随机会话；内存密钥；公开 HTTPS 地址检查、DNS 固定、TLS 校验、重定向拒绝；模型请求/预算限制；WebDAV 条件写入。

安全边界：

- 加密不防止解锁时的恶意同源代码、扩展、系统控制或内存读取。密码不能重置，旧明文记录物理擦除不作保证。
- TXT 导出是明文；云端可见快照元数据。模型收到用户明确发送的明文片段。
- 模型 token 上限是本机会话保护，不是账单金额硬限额。新会话可重新计数；未知失败可能仍收费，默认不自动重试。
- 本机服务只监听 loopback、只提供发布白名单文件；不应添加公网代理或绕过 Origin 检查。
- RAG 的出处编号验证不能保证语义真实性，提示词注入仍可能影响回答；模型没有工具执行、文件覆盖或自动上传权限。
- WebDAV 依赖服务商正确实现强 ETag 与条件写入，不支持的服务不能安全覆盖；真实提供商尚未验收。
- 历史整理必须先备份。40 MiB 快照上限、整库加密写入和浏览器驱逐仍是容量边界。
- 实体手机、物理故障、安全专业审计尚未完成。测试通过不等于不存在漏洞。

发现问题时不要在公开 Issue 贴稿件、备份或密钥。若仓库启用私密漏洞报告，使用 Security 页面；否则私下联系仓库所有者。不伪造支持邮箱，不承诺安全认证。

0.3.0 章节协作依赖固定版本 Yjs/lib0，浏览器文件和许可证随源码包发布。CRDT 保证更新收敛，不保证合并后的句子语义正确。WebDAV 条件写入仍依赖服务商正确实现强 ETag；后台标签页可能降低轮询频率。协作密码不能找回，遗失后远端密文无法解密。真实 WebDAV 与物理多设备仍待验证。
