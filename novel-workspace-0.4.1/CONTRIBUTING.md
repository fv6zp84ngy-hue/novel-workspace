# 参与开发

先读 [需求范围](docs/REQUIREMENTS.md) 与 [技术规格](docs/SPEC.md)。本版维持原生前端、Python 标准库启动器、无第三方运行依赖。

1. 在自己的分支完成一个明确的小改动。
2. 更新代码对应的功能说明、测试及 `release-manifest.json`。
3. 执行 `python3 -B scripts/check.py`；涉及存储、恢复、导入时还需运行 `tests/browser.html`。
4. 使用自编素材和 `?qa=1` 测试区，不使用真实稿件。
5. PR 说明问题、改动、验证与限制，不把模板写成 AI。

测试代码、公开文档和示例中禁止放入账号、访问令牌、私密路径、用户备份。CI 仅有仓库读取权限；远程测试状态以目标仓库实际运行结果为准。
